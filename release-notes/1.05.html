What's New in 1.05

You can now restore files from any snapshot directly from inside Project Backuper — no Terminal required.

  • New: "Restore Files…" button in the Activity Log window. Select any successful snapshot in the list, click the button, and the new Restore window opens showing every file in that snapshot with a checkbox. Pick what you want, click "Restore To…", choose a destination folder, and the app writes the selected files out as real regular files — with their original filenames and folder structure preserved. Works in both hardlink and symlink modes.
  • New: Why this matters in symlink mode: when Project Backuper falls back to symlinks (NAS destinations), Finder copies of project files in a snapshot folder just give you a 1KB symlink, not the real file. The Restore window resolves each symlink server-side using /usr/bin/ditto -L so you always get a usable file.
  • New: "ⓘ" Help button in the Restore window shows the equivalent ditto command if you'd rather batch a restore from Terminal or script it into something else.
  • New: After a restore, a confirmation dialog offers "Show in Finder" to jump straight to the restored files.

What's New in 1.04

Hotfix for v1.03 symlink mode — project files now open directly from snapshot folders.

  • Fixed: Store objects keep the original file extension (store/ab/abcd….prproj instead of store/ab/abcd…). Symlinks in snapshot folders now resolve to a target macOS recognizes, so double-click opens in Premiere / After Effects / Photoshop / Illustrator as expected.

What's New in 1.03

NAS-compatibility release: Project Backuper works on SMB shares that don't support hardlinks (QNAP and Synology over SMB).

  • New: Automatic symlink fallback for destinations that reject link(2). Picker probes at destination-pick time, falls back to relative symbolic links, surfaces the choice in Settings → Setup as a "Link mode: …" label.
