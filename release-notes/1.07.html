What's New in 1.07

Restore Files gets a major upgrade: more access points, a snapshot picker, column sorting, and a brand-new Restore to Original Location action.

  • New — Menu bar entry: "Restore Files…" is now in the main Project Backuper menu (right under "Show Activity Log…"). Opens the Restore window with no preselected snapshot — defaults to the newest, picker at the top lets you switch.
  • New — Settings tab: "Restore Files" is now a tab in Settings, between File Types and Advanced. Same UI as the standalone window. Use whichever surface fits your workflow.
  • New — Snapshot picker: Both the window and the tab have a "Snapshot:" dropdown at the top listing your last 200 snapshots, newest first, with human-readable timestamps. Switch snapshots without closing and reopening.
  • New — Column sorting: Click any column header (File / Size / Modified) in the Restore table to sort. Sizes and dates default to descending (largest / newest first). Selection survives the resort.
  • New — Restore to Original Location: A second restore button next to "Restore To…". Writes each selected file back to the source folder it came from at backup time (e.g. /Volumes/8TB/Projects/…). Existing files are never overwritten — renamed " (1)", " (2)", … just like the main Restore To flow. Useful for accidental-delete recovery — one click puts the file back where it belongs.
  • Internal: The Restore window and the Restore Files tab are now the same view controller under the hood — one implementation, two surfaces. Behavior is identical.
