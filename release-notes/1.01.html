What's New in 1.01

Polish release focused on safer destination handling and a friendlier settings experience.

  • New: Click any column header in the Index Report to sort by that column. Click again to reverse. Selection survives the resort.
  • New: Settings window opens automatically when you launch Project Backuper from Applications, Spotlight, or the Dock — but stays quiet in the menu bar when started at login or after a restart, so it doesn't pop a window in your face every time you boot.
  • New: The backup destination path is now clickable in Settings → Setup. Click the path to choose a different folder; the separate "Choose…" button only appears when no destination has been set yet.
  • New: Settings → Advanced has a View Release Notes link that opens this page in your browser, so you can see what's in each release whenever you want.
  • New: The Sources table has a labeled "Enabled" column with a tooltip explaining that unchecked folders are skipped on every backup pass.
  • Safer: The destination picker now blocks you from picking a folder that overlaps a source (in either direction) — that would cause Project Backuper to back up its own snapshots recursively. Hard block, no override.
  • Safer: If you pick a destination that already contains snapshots from a different Project Backuper install, the app warns you that continuing would garbage-collect that data on the next retention pass. Default is Cancel.
  • Friendlier: If the folder you pick isn't empty and isn't a prior Project Backuper destination, the app offers to create a ProjectBackuper subfolder inside it so your snapshots don't mix with your other files.

What's New in 1.0 — Initial Release

First public release. Project Backuper is a menu-bar app that backs up Adobe project files (Premiere Pro, After Effects, Photoshop, Illustrator) on a schedule, with hardlink-based deduplication.

  • Snapshot history with a Time Machine-style cadence (30 min to 24 h). Every snapshot lives at <destination>/Snapshots/<timestamp>/ and can be opened directly in Finder.
  • Real deduplication. A single content-addressed object store under .projectbackuper/store/ holds each unique file once. Snapshot folders are pure hardlink trees, so unchanged files cost zero additional disk space.
  • "Last Backup" shortcut. A symlink at the destination root always points at the most recent snapshot.
  • Activity Log window (menu bar → Show Activity Log) shows every backup attempt — success, skip, failure, cancellation — with timings, byte counts, and the resulting snapshot ID. CSV export available.
  • LucidLink aware. Detects LucidLink mounts and switches to a metadata-light fast enumeration. Warns before using LucidLink as a destination (hardlinks are unreliable there).
  • Pause control. Pausing the schedule shows a dedicated pause icon in the menu bar so the state is obvious at a glance.
  • Retention. Choose between simple (keep last N) or tiered (Time Machine-style hourly / daily / weekly).
  • Sparkle auto-updates with EdDSA signing, plus a manual Check for Updates… menu item.
