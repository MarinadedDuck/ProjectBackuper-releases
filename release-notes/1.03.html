What's New in 1.03

Big one: Project Backuper now works on NAS shares that don't support hardlinks (QNAP and Synology over SMB are the common cases).

  • New: Symlink fallback for NAS destinations. When you pick a destination, the app now probes whether the volume supports hardlinks. If it does, nothing changes — you keep the original hardlink-based behavior. If hardlinks aren't supported (SMB shares on most NAS units), the app automatically falls back to relative symbolic links instead. Same deduplication, same snapshot browsing, same retention behavior — the snapshot folders just show files with the small link-arrow badge in Finder.
  • New: Destination picker tells you which link mode it picked, via an info dialog when the symlink fallback kicks in. Settings → Setup → the destination panel now also shows the current mode ("Link mode: Hardlinks" or "Link mode: Symlinks (NAS-compatible)") so you can confirm at a glance.
  • New: If neither hardlinks nor symlinks work on the volume you picked, the destination is refused with a clear error explaining that Project Backuper needs at least one of them — usually a sign that you should use NFS instead of SMB, or pick a local disk.
  • Internal: The link-mode choice is persisted in <destination>/.projectbackuper/link-mode (a tiny text file containing hardlink or symlink). Survives reboots and remounts. Edit by hand if you really need to.

What's New in 1.02

Small UX tweaks plus more sensible out-of-the-box defaults.

  • Changed: The Simple retention setting is now a single-line sentence — "Simple — Keep last [N] snapshots" with the number editable inline next to the radio button. No more two-row label-plus-stepper layout.
  • Changed: The default backup schedule is now Every 4 hours (was: Every hour). More reasonable for typical creative project workflows.
  • Changed: The default retention is now 40 snapshots (was: 24). Combined with the 4-hour cadence, that's just under a week of history out of the box.
  • Removed: The "Every minute" and "Every 5 minutes" schedule options — those were development-only affordances and shouldn't have been in the released build.

What's New in 1.01

Polish release focused on safer destination handling and a friendlier settings experience.

  • New: Click any column header in the Index Report to sort.
  • New: Settings opens automatically when launched by the user; stays quiet for login-item and post-restart resume.
  • New: Clickable destination path replaces the "Choose…" button once a destination is set.
  • New: Advanced tab has a View Release Notes link.
  • New: The Sources column header is now labeled "Enabled".
  • Safer: Destination picker blocks folders that overlap a source (recursive backups), warns on foreign Project Backuper data, and offers a subfolder when the chosen folder isn't empty.
  • Fixed: Sparkle auto-update wiring — v1.0 was missing the appcast URL in its Info.plist.

What's New in 1.0 — Initial Release

First public release. Project Backuper is a menu-bar app that backs up Adobe project files (Premiere Pro, After Effects, Photoshop, Illustrator) on a schedule, with hardlink-based deduplication.

  • Snapshot history (30 min – 24 h cadence) with hardlink-based deduplication via a content-addressed store.
  • "Last Backup" symlink at the destination root always points at the most recent snapshot.
  • Activity Log with timings, byte counts, and snapshot IDs.
  • LucidLink-aware fast enumeration.
  • Pause control with dedicated menu-bar icon.
  • Simple and tiered retention policies.
  • Sparkle auto-updates with EdDSA signing.
